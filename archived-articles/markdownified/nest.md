# Nest
Nest is a free Linux-based web hosting service provided by Hack Club, primarily aimed at teenagers and students for hosting web applications, projects, and other software. The service is modeled after the concept of a Tilde, which allows students to share computing resources in a communal environment. Nest provides users with shell access, Git repositories, and other development tools without the need for paid hosting.

## Overview
Nest is operated and maintained by Hack Club volunteers, with infrastructure hosted on a dedicated Hetzner server located in Helsinki, Finland. It enforces user resource limits to prevent abuse and ensure equitable access for all users.

## Infrastructure
### Hardware
The primary server is a Hetzner AX162-R dedicated server with the following specifications:

- AMD EPYC Genoa 9454P processor
- 256 GB DDR5 RAM
- 2 × 1.92 TB NVMe SSDs
- Gigabit internet connection

## Data Management
Nest provides transparency regarding user data, including storage locations and access procedures. Data is stored primarily in users' home directories and associated databases across the Nest intranet. Nest tends to operate with the GDPR privacy framework.
